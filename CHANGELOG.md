# Changelog

## [1.0.0] - 2026-08-16

### Added
- Architettura definitiva del Roncegno Civic Design System.
- Brand architecture Comune / Visit Roncegno / canali editoriali.
- Palette istituzionale e semantica consolidata.
- Sistema tipografico Cormorant Garamond + Inter.
- Design token CSS e JSON per colori, tipografia, spaziature, raggi e ombre.
- Regole fotografiche e motion identity.
- Content model per informazione, eventi, territorio, comunità, progetti ed emergenze.
- Linee guida Instagram, Facebook, VisitRoncegno, stampa, notiziario e totem.
- Editorial Playbook con criteri di scrittura e adattamento multicanale.
- AI Toolkit e policy di verifica umana.
- Governance, flusso di approvazione e checklist qualità.
- Portale HTML v1.0 per GitHub Pages.

### Changed
- Il RCDS è definito come layer complementare al Design System .italia per il sito istituzionale.
- Visit Roncegno è trattato come estensione territoriale dello stesso ecosistema visivo, non come brand scollegato.
- I template sono organizzati per contenuto e layout riutilizzabile, non soltanto per canale.
