# Template System — v1.0

I template RCDS sono layout modulari, non grafiche da replicare rigidamente.

## Formato social

Instagram usa come standard 1080×1350 px (4:5). Facebook può riutilizzare gli stessi asset quando opportuno o usare formati orizzontali dedicati.

## Famiglie

- Benvenuto / Hero
- Evento
- Agenda
- Informazione / Servizio
- Progetto / Lavori
- Comunità / Associazioni
- Territorio / Scopri Roncegno
- Cultura / Tradizioni
- Emergenza
- Reel cover / Story

## Componenti ricorrenti

- categoria;
- titolo;
- data e luogo;
- immagine;
- testo breve;
- call to action;
- firma istituzionale.

Non tutti i componenti devono apparire sempre.

## Canva

Canva è considerato un editor operativo, non la sorgente del design. Gli SVG master devono poter essere importati in Canva, Figma, Illustrator o Inkscape senza dipendere da una singola piattaforma.

## Stemma

Usare solo asset ufficiali. Nessun template deve contenere ricostruzioni, stemmi generati o versioni approssimative.
