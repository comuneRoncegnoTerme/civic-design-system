# Roncegno Civic Design System (RCDS)

**Versione 1.0 — release candidata all'adozione**

Il RCDS è il sistema di comunicazione visiva ed editoriale del Comune di Roncegno Terme. Definisce principi, linguaggio, design token, template e regole operative per una comunicazione pubblica coerente, accessibile e riconoscibile.

## Ambito

Il sistema si applica a:

- Instagram e Facebook del Comune;
- VisitRoncegno.it e comunicazione territoriale;
- notiziario comunale;
- manifesti, locandine, brochure e materiali di evento;
- video, reel e totem multimediali;
- presentazioni e materiali interni;
- prompt e workflow assistiti da IA.

Il sito istituzionale `comune.roncegnoterme.tn.it` resta basato sul Design System .italia: il RCDS ne completa il livello editoriale e fotografico senza sostituirne componenti, struttura o requisiti normativi.

## Identità

**Principio guida:** _Informare la comunità. Raccontare il territorio._

**Firma editoriale:** _Insieme, ogni giorno._

**Direzione visiva:** Alpino contemporaneo + Civico moderno.

**Tipografia:** Cormorant Garamond per display e titoli; Inter per testi, interfacce e informazioni.

## Struttura

- `brand-book/` — identità, principi e linee guida
- `design-system/` — regole visive e componenti
- `tokens/` — design token in CSS e JSON
- `templates/` — layout e formati operativi
- `governance/` — processi e responsabilità
- `prompts/` — toolkit IA
- `docs/` — portale documentale pubblicabile con GitHub Pages
